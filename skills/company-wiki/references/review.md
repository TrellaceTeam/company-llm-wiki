# Review

Review what ingest wrote, as an editor reads a junior writer's drafts. Each source was read alone, so ingest never saw the batch side by side, and it slips in known ways: a plan written up as done, a name spelled two ways, a pronoun no source used, a fact in the wrong folder, a citation whose number points at the wrong source. Run and backfill send you here after every ten sources. Use the strongest model the app lets you pick, in a fresh helper when you can.

## 1. Read the batch

Take the batch's sources and the pages each one created or changed, from the log lines and ledger rows of this run. Read each page, the wiki's index, `company/structure.md` and the index of every folder the batch touched.

**Done when** you know every page the batch created or changed and where each one sits.

## 2. Check each page

- **Facts a teammate would act on.** Open the source behind each number, date, name, role, price and status the batch added, and confirm the claim. Before you call a name or fact unsupported, search the source folders and the wiki for it, since another source often gives what one leaves out. A plan, draft, proposal or question written up as done is wrong. So is a dropped hedge that changes what a reader would do, and a pronoun no source uses.
- **Placement.** Every fact sits where its subject decides, by the placement rules in `SKILL.md` and `company/structure.md`. A page named after a document, such as one board update or one meeting, is a summary in the wrong shape: move its facts to the pages for their subjects.
- **One subject, one page.** Two pages that answer the same question become one, under the better name. A person, company or product spelled two ways takes the most formal source's spelling everywhere.
- **Format.** Each page has its title, question, status line, answer, Sources list and folder index line. Every number in square brackets has its Sources entry, and every entry is cited.

**Done when** every page in the batch passes all four checks.

## 3. Fix

Fix substance only: a claim its source doesn't support, a misplaced fact, a duplicate page, a name spelled two ways, a missing part of the format. Leave wording and style as ingest wrote them. Change the wrong claim and keep its citation, by every page rule in `SKILL.md`. Update the status line of each page you change. Move or merge a page as `company/home.md` says.

**Done when** every problem from step 2 is fixed.

## 4. Log it

Add these lines to the run's log entry: one per fix, "Fixed {page}: {what was wrong and what it says now}". One per page you moved or merged, "Moved {page} to {folder}: {why}". One per slip you saw in two or more sources, "Pattern: {the slip}". When every check passes, write "Review: no fixes needed."

A pattern is a candidate house rule. Add it under "Setup suggestions" with the line you'd put in `company/style.md`, so the next ingest avoids it.
