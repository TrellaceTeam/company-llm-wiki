# Home

How to work in this wiki's home, Google Drive. Written by setup on 14 October 2026 from the Google Drive section of homes.md. Edit any line, or ask for a change in plain words.

## Layout
- Wiki: the Fennick Wiki folder in Priya's My Drive, shared with everyone at Fennick. One subfolder per fixed and suggested folder in structure.md, each with a "{Folder} index" Doc. Pages are Google Docs.
- Index: the Index Doc at the top of the wiki folder
- System: the Fennick Wiki system folder in Priya's My Drive, shared with no one, with the Wiki log Doc, the Wiki ledger Sheet and the Wiki test page

## Writing a page
- Create: a new Google Doc in the page's folder, titled with the subject
- Format: the title as Title, the question in italics, the status line as plain text, sections as Heading 2 and 3, Sources as a numbered list
- Change: edit the Doc in place with the Google Docs tools
- Fallback: none needed

## Links
- A page: its Doc link, with the page's title as the link text
- A source: its Drive file link, or for #ops the link to the day's first message

## Finding pages
- Search Drive for the title inside the Fennick Wiki folder, and read the folder index
- The pages one source built: its Pages cell in the ledger

## Moving and merging
- Move the Doc to its new folder, then update both folder indexes
- Merge into the kept page, point every link at it, and leave the other page as one line, "Merged into {link} on {date}." Tidy trashes it later

## Log and ledger
- Log: the Wiki log Doc, newest entry first, below the "Held for Priya Raman" and "Setup suggestions" sections
- Ledger: the Wiki ledger Sheet, one row per source file, with the columns Source, File, Link, File ID, Last changed, Read on, Pages, Status, Note

## Sharing
- Wiki: everyone at Fennick, as Commenter
- Corrections: everyone at Fennick, as Editor
- System: no one but Priya Raman, its owner
