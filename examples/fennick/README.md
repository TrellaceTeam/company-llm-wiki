# Example: Fennick Software

Fennick Software and everyone named here are fictional. Fennick sells maintenance software to mid-size manufacturers. This folder shows what you end up with after setup: the setup the skill saves inside your copy, and two wiki pages as they read in Google Docs.

Every link here is a placeholder, so none of them opens. Nothing in this folder ran against a real Google Drive.
